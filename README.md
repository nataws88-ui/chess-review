# ♟️ 체스 복기왕

**내가 둔 실수를, 내 문제로 다시 푼다.**

[![빌드](https://github.com/nataws88-ui/chess-review/actions/workflows/build.yml/badge.svg)](https://github.com/nataws88-ui/chess-review/actions)
· [개인정보 처리방침](https://nataws88-ui.github.io/chess-review/store/privacy-policy.html)

내 경기(PGN)를 스톡피시가 분석해 실수를 찾아내고, 그 장면을 **판에서 직접 두어 답하는 문제**로
만들어 줍니다. 틀린 문제는 안키식 간격 반복(1→3→7→14→30→60일)으로 다시 나옵니다.

엔진은 앱 안에 들어 있어 **인터넷 없이** 동작합니다. AI·서버·계정 없음.
무료 유지를 위해 광고(AdMob)가 붙어 있지만 **체스판이 뜨는 화면에는 광고가 없습니다** —
배너는 목록·통계·설정 화면에만, 전면광고는 분석·훈련을 마친 뒤에만 나옵니다.

## 기존 「체스 퀴즈」와의 관계

기존 시스템(`/root/chess`, 폰 로컬 서버 + 파이썬)은 **그대로 둡니다.** 계속 쓸 수 있습니다.
이 앱은 그것을 앱으로 다시 만든 것이고, 하던 진도는 그대로 옮겨올 수 있습니다.

| |기존 (체스 퀴즈)|이 앱 (체스 복기왕)|
|---|---|---|
|실행|Termux + 파이썬 + 로컬 서버|앱 하나 (Termux 불필요)|
|엔진|폰의 스톡피시 바이너리|앱에 내장(arm64)|
|AI 코치|🧠 클로드 코치 있음|**없음 — 엔진 전용**|
|분석|PC/Termux에서 build.sh|앱 안에서 바로|
|경기 추가|공유 → Termux 스크립트|공유받기 + 체스닷컴 자동 가져오기|
|그래픽|PNG 비트맵(강제 다크모드 우회용)|**벡터 SVG + 애니메이션**|
|추가 기능|—|엔진 대국·실력 통계·약점 리포트|

### 하던 진도 옮기기

```bash
python3 tools/export_from_old.py    # 경기+분석을 /sdcard/체스퀴즈/ 로 내보내고
                                    # 같은 폴더에 '앱이전.html' 을 설치한다
```
1. 폰 브라우저에서 **http://127.0.0.1:8123/앱이전.html** 열기 (기존 서버가 켜져 있어야 함)
2. **[완성 파일 만들기]** — 경기·분석 + 이 브라우저의 훈련 진도(`cq_srs_v1`)를 한 파일로 저장
3. 앱에서 **설정 → 데이터 → 📥 가져오기** → 그 파일 선택

진도는 브라우저 localStorage 안에만 있어서 파일로는 못 읽습니다. 그래서 페이지가
직접 읽어 합칩니다. 경기 ID를 기존 파일명 그대로 쓰기 때문에 **문제별 복습 간격까지
그대로** 이어집니다.

## 기능

- **경기 가져오기** — 체스닷컴 아이디로 자동 / PGN 붙여넣기 / 다른 앱에서 공유 / 파일
- **엔진 분석** — 수마다 최선수·승률을 계산, 실수(승률 -12%p↑)를 자동 검출
- **🧩 문제** — 판에서 직접 기물을 움직여 답하기, 정답 후 번호 붙은 화살표로 수순 표시
  - 🟢 최선 수순 / 🔴 실전에서 당한 응징 / 🟠 **내가 둔 틀린 수의 결과**(엔진이 즉석 계산)
  - 원인 규명: 무엇이 걸리는지, 상대가 어떻게 응징하는지, 승률이 몇 %p 떨어지는지
- **🎬 복기** — 수마다 품질 배지·승률 막대·최선 수순 화살표, 평가 그래프와 양방향 연동
- **📊 리포트** — 정확도·추정 레이팅·평균 손실(CPL)·구간별 정확도·수 품질 분포
- **🎯 훈련** — 전 경기 문제를 모아 간격 반복, 틀리면 곧 다시 출제, 하던 자리 이어하기
- **⚔️ 엔진 대국** — 6단계 난이도, 무르기·힌트·승률바, 둔 대국을 그대로 분석해 문제로
- **📈 통계** — 정확도 추이, 실수 원인 분류(기물 방치/전술/메이트/판단), 오프닝별 성적,
  자꾸 틀리는 문제 Top 5

### 1.3.0 에서 들어온 것 (Chessis 9.2 해부 후 이식)

- **🔬 분석판** — 아무 국면이나 놓고 보는 자유 판. 엔진 후보 수(라인) 1~5줄, 그 라인을 그대로
  놔 보기, 판 만들기(기물 배치·캐슬링 권한·둘 차례), FEN/PGN 주고받기, 손으로 화살표 그리기
- **🔍 국면 읽기 9가지** — 핀 걸린 기물 · 지켜지지 않는 기물 · 기물 활동성(칸마다 숫자) ·
  통과한 폰 · 고립 폰 · 뒤처진 폰 · 잡히기 쉬운 킹 · 발견 공격 · 포크 가능 칸.
  **엔진 없이 판만 보고** 내므로 즉시 뜬다. 복기·대국·문제·분석판 어디서나 켤 수 있다
- **⚠️ 위협** — 지금 상대 차례라면 뭐가 오는지(재료 손실·메이트·무방비 기물)를 화살표로
- **🎓 배우기** — 요소 아홉 가지를 예제 국면으로 하나씩
- **경기 보관함** — 태그 · 즐겨찾기 · 결과/색/정렬 거르개 · **국면(FEN)으로 찾기** ·
  여러 판 골라 지우기 · PGN 고치기 · 다시 분석
- **📖 오프닝** — 내 경기를 오프닝별로 묶어 승률·평균 정확도
- **빠른 리포트 / 정밀 리포트** — 시간 기준·깊이 기준 선택, **이미 분석한 국면은 건너뛰기**
  (국면 보관함에 쌓아 두어 다른 판에서도 다시 쓴다), 끝나면 알림
- **대국 강화** — 시계(증가 시간) · 무르기 시 상대에게 +10초 · 기권/무승부 제안 ·
  **내 수 강도 실시간** · **블런더·실수에서 자동 정지 + 왜 나빴나** · 지난 대국 이어하기 ·
  사람처럼 두는 상대 3단 · 무작위 배치(체스960 배치)
- **판 꾸미기** — 기물 세트 **ZIP 으로 넣기** · 칸 색 직접 고르기 · 판 배경 그림 ·
  마지막 수 강조 유형 · 피규린 표기(♘f3) · 전체 화면

### 1.4.0 에서 들어온 것

- **🧩 퍼즐** (리체스 training 방식) — 상대가 실수를 두는 것을 눈앞에서 보고, 그 자리에서
  응징하는 수를 찾는다. 맞히면 내 **퍼즐 점수**가 오르고 더 어려운 문제가 나온다.
  주제(양걸이·핀·꼬치·열린 공격·백랭크·희생·메이트…)로 골라 풀 수 있고,
  **주제별 성적**이 쌓여 뭐가 약한지 보인다
  - 문제는 두 군데서 온다: **내 경기의 실수**(분석 결과에서 자동으로 캔다) +
    **기본 꾸러미 526개**(스톡피시끼리 둔 620판에서 캐 하나하나 검증한 것 —
    한 수 메이트 86 · 두 수 24 · 세 수 23 · 백랭크 25 · 핀 151 · 희생 134 …)
- **🔥 연속 도전** — 목숨 3개. 틀리기 전까지 몇 개나 맞히나. 맞힐수록 어려워진다
- **🎓 연습 코스** (리체스 practice 방식) — 기본 메이트(퀸·룩·두 룩·두 비숍) ·
  메이트 모양(백랭크·아라비안·아나스타시아·질식·퀸 밀착) · 폰 엔딩(오포지션·돌파) ·
  룩 엔딩(루체나·폰 뒤에서 밀기·버텨서 비기기) · 못 이기는 자리 알기 · 전술 주제 9가지.
  **엔진을 상대로 직접 두고**, 목표를 놓치는 수를 두면 그 자리에서 물러 준다
- **화살표를 굵게** — 보통·크게·아주 크게. 기본이 「크게」로 바뀌었다
- **끌어서(밀어서) 옮기기** — 기물을 눌러 그대로 끌면 손가락을 따라온다. 눌러서 고르는
  옛 방식도 그대로 된다
- **타격감** — 수를 놓으면 도착 칸에서 파장이 퍼지고, 잡는 수는 판이 살짝 흔들린다.
  소리도 다시 만들었다(놓는 소리·잡는 소리·체크·캐슬링·승격), 진동도 종류마다 다르다
- **판 색이 깜빡이던 것 고침** — 문제 화면이 기본색으로 한 번 그렸다가 설정색으로 다시
  그리던 문제. 설정을 기다리지 않고 바로 쓰도록 바꿨다

### 왜 이렇게 만들었나

- **엔진을 `.so` 이름으로 넣는 이유** — 안드로이드 10부터 앱 데이터 폴더의 파일은 실행할 수
  없습니다. 설치 때 풀리는 네이티브 라이브러리 폴더만 예외라서, 스톡피시 바이너리를
  `libstockfish.so` 로 넣고 그 경로를 실행합니다 (`useLegacyPackaging = true` 필수).
- **웹 자산을 `https://appassets.androidplatform.net` 으로 제공하는 이유** — `file://` 에서는
  ES 모듈·fetch 가 막힙니다. `WebViewAssetLoader` 로 정상 오리진처럼 제공합니다.
- **강제 다크모드 차단** — 기존 HTML판은 폰 브라우저의 강제 다크모드가 SVG 색까지 반전시켜
  기물을 전부 PNG로 우회해야 했습니다. 앱에서는 `setAlgorithmicDarkeningAllowed(false)` 로
  껐기 때문에 벡터·그라데이션·애니메이션을 마음껏 씁니다.

## 개발

```bash
bash test/all.sh           # 전체 검사 (아래 5가지를 한 번에)
  node test/smoke.mjs      #   모듈 적재 — 문법·import
  bash test/javacheck.sh   #   안드로이드 자바 타입 검사 (API 스텁 컴파일)
  node test/run.mjs        #   실제 스톡피시로 종단 (분석→문제→기존 데이터 이전)
  node test/views.mjs      #   모든 화면 렌더 + 문제 풀이 동작 시뮬레이션
  node test/preview.mjs    #   판 렌더 결과를 PNG 로 (test/preview/)

./serve.sh                 # 브라우저 미리보기 (엔진 빼고 화면 확인)
bash tools/fetch_engine.sh # 엔진 바이너리 준비 (로컬 빌드용)
bash tools/publish.sh      # GitHub 올리기 + 서명키 + Pages + 빌드 (gh auth login 후)
```

> 안드로이드 SDK는 x86_64 전용이라 이 폰(arm64)에서는 APK를 만들 수 없습니다.
> 그래서 빌드는 GitHub Actions에서 하고, 대신 위 검사들로 설치 전에 최대한 잡습니다.

빌드는 GitHub Actions에서 합니다 → [PLAYSTORE.md](PLAYSTORE.md)
