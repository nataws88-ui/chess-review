## ① 그래픽 이미지 올리기 (2분)

1. 왼쪽 메뉴 **사용자 늘리기 → 앱 정보 → 스토어 등록정보**
2. 아래로 스크롤 → **그래픽 이미지** 항목의 `애셋 추가`
3. 오른쪽 패널 아래 **업로드 → 파일 선택** → 이 폴더의 `feature-1024x500.png`
4. `추가` → 패널 닫기(X) → 오른쪽 아래 **저장**

> 규격은 이미 맞춰져 있습니다(1024×500 PNG). 잘리거나 거부되지 않습니다.

## ② AAB 올리고 비공개 테스트 시작 (8분)

1. 왼쪽 메뉴 **테스트 및 출시 → 테스트 → 비공개 테스트**
2. 오른쪽 위 **새 버전 만들기**
3. **App Bundle** 칸에 `체스복기왕-1.0.0.aab` 드래그해서 올리기
   - "Play 앱 서명을 사용하시겠습니까?" → **계속/사용** (권장 — 업로드 키를 잃어도 구글이 복구해 줍니다)
4. 출시명 `1.0.0` · 출시 노트에 아래 한 줄 붙여넣기
   ```
   <ko-KR>첫 출시입니다. 내 경기를 엔진으로 분석해 실수를 문제로 만들어 복습합니다.</ko-KR>
   ```
5. **저장 → 버전 검토 → 비공개 테스트로 출시 시작**
6. 같은 화면의 **테스터** 탭 → **이메일 목록 만들기** → 목록 이름 아무거나 →
   지인 Gmail 주소 **12개 이상** 붙여넣기(쉼표로 구분) → 저장 → 목록 체크
7. 맨 아래 **참여 링크(opt-in URL)** 복사

## 앱을 고쳐서 다시 올릴 때 (참고)

폰 Termux에서:
```bash
cd /root/chess-app
# android/app/build.gradle 에서 versionCode 1 → 2, versionName "1.0.0" → "1.0.1"
git add -A && git commit -m "1.0.1" && git push
gh workflow run "Build Android" && gh run watch
gh run download -n aab-play-upload -D /root/chess-out
rclone copy /root/chess-out/app-release.aab gdrive:체스복기왕-스토어/ -P
```
