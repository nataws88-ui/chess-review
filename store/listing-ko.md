# Play 스토어 등록 문구 (한국어)

## 앱 이름 (30자 이내)
```
체스 복기왕
```

## 짧은 설명 (80자 이내)
```
내 경기를 엔진이 분석해 실수를 문제로. 판에서 직접 두며 복습하는 체스 복기 앱.
```

## 전체 설명 (4000자 이내)
```
♟️ 진 이유를 모르면, 같은 실수를 또 합니다.

체스 복기왕은 내가 둔 경기를 강력한 체스 엔진(스톡피시 17.1)으로 분석해
"어디서 무너졌는지"를 찾아내고, 그 장면을 문제로 만들어 다시 풀게 합니다.

읽고 넘기는 복기가 아니라, 판 위에서 직접 기물을 움직여 답하는 복습입니다.


■ 이렇게 씁니다

1. 경기를 가져옵니다
   · 체스닷컴 아이디만 넣으면 최근 경기를 자동으로
   · 다른 앱에서 PGN을 "공유"해도 바로 들어옵니다
   · PGN 붙여넣기, 파일 열기도 지원

2. 엔진이 한 수씩 분석합니다
   · 수마다 최선수와 승률을 계산
   · 승률이 크게 떨어진 수를 실수로 자동 검출
   · 지적된 수는 더 깊게 다시 계산해 재검증

3. 실수가 문제가 됩니다
   · "여기서 최선은?" — 판에서 직접 두어 답합니다
   · 정답 후 번호 붙은 화살표로 수순을 보여 줍니다
      🟢 최선 수순  🔴 실전에서 당한 응징  🟠 내가 둔 수의 결과
   · 왜 그 수가 최선인지, 내 수는 무엇이 문제였는지 한국어로 설명합니다

4. 잊을 때쯤 다시 나옵니다
   · 안키식 간격 반복: 맞히면 1 → 3 → 7 → 14 → 30 → 60일 뒤 다시
   · 틀리면 그 자리에서 곧 다시 출제


■ 주요 기능

🧩 문제 풀기 — 실수 장면을 판에서 직접 두어 복습
🎬 복기 — 수마다 품질 배지(최선·부정확·실수·블런더)와 승률, 최선 수순 화살표
📊 경기 리포트 — 정확도, 추정 레이팅, 평균 손실(CPL), 구간별 정확도
🎯 오늘의 훈련 — 모든 경기의 실수를 모아 간격 반복으로
⚔️ 엔진 대국 — 입문부터 최강까지 6단계, 무르기·힌트 지원. 둔 대국도 바로 분석
📈 실력 통계 — 정확도 추이, 실수 원인 분석, 오프닝별 성적, 자꾸 틀리는 문제


■ 이런 분께

· 체스닷컴/리체스에서 두는데 실력이 정체된 분
· 복기를 해야 하는 건 아는데 뭘 봐야 할지 모르겠는 분
· 같은 실수를 반복하는 게 느껴지는 분
· 이동 중에도 짧게 복습하고 싶은 분


■ 약속

· 오프라인 동작 — 분석도 대국도 인터넷 없이 됩니다
  (인터넷은 체스닷컴에서 경기를 가져올 때와 광고를 받을 때만 씁니다)
· 계정 없음 — 가입도 로그인도 없습니다
· 결제 없음 — 모든 기능이 무료입니다
· 광고는 체스판을 가리지 않습니다 — 판이 뜨는 화면에는 광고가 없고,
  배너는 목록·통계 화면 하단에만, 전면 광고는 분석·훈련을 마친 뒤에만 나옵니다
· 기록은 전부 내 기기 안에만 저장됩니다. 개발자 서버로 보내지 않습니다


■ 오픈소스

이 앱은 GPLv3로 배포되며 소스가 공개되어 있습니다.
엔진: Stockfish 17.1 (GPLv3) · 수 처리: chess.js (BSD) · 기물: Colin M.L. Burnett
```

## 카테고리
- 앱 카테고리: **게임 > 보드** (또는 앱 > 교육 — 학습 도구 성격이 강하면 이쪽)
- 태그: 체스, 퍼즐, 학습

## 콘텐츠 등급
- 전체이용가 (폭력·구매·사용자간 소통 없음)
- ⚠️ 설문에서 **"앱에 광고가 포함되어 있습니다" 를 반드시 예로** 답해야 합니다 (AdMob 배너·전면광고 있음)
- 광고 자체도 전체이용가(G) 등급으로 제한해 두었습니다 (`Ads.java` 의 MAX_AD_CONTENT_RATING_G)

## 앱 콘텐츠 — 광고
- **앱에 광고가 있습니다: 예**
- 스토어 등록정보의 "광고 포함" 배지가 붙습니다 (정상)

## 데이터 보안 (Data safety) 설문 답변
광고를 넣었으므로 "수집 없음"이 아닙니다. 아래처럼 답합니다.

| 항목 | 답 |
|---|---|
| 데이터 수집 | **예** (광고 SDK가 수집) |
| 수집 항목 | `기기 또는 다른 ID` → **기기 또는 다른 ID** (광고 ID) / `앱 활동` → 앱 상호작용(광고 노출·클릭) |
| 수집 목적 | **광고 또는 마케팅**, 분석(광고 성과 측정) |
| 데이터 공유 | **예** — 광고 제공을 위해 Google 및 광고 파트너와 공유 |
| 필수 여부 | **필수** (앱 안에서 광고를 끄는 수단이 없으므로 "선택 사항 아님"으로 답합니다) |
| 전송 중 암호화 | **예** (광고 요청·체스닷컴 API 모두 HTTPS) |
| 데이터 삭제 요청 | 광고 ID는 기기 설정에서 초기화·삭제 가능 · 앱 내 [전체 데이터 삭제] 제공 |

> 체스 경기·분석 결과·입력한 아이디는 **수집 대상이 아닙니다**(기기 안에만 저장).
> 광고 SDK가 수집하는 것은 광고 ID와 광고 상호작용 정보이며 개발자는 집계 통계만 봅니다.
> 개인정보처리방침(`store/privacy-policy.html`)의 2항과 내용이 일치해야 심사에서 문제가 없습니다.

## 스크린샷 (필수: 휴대전화 2장 이상, 최대 8장)
설치 후 실제 화면을 찍는 게 가장 좋습니다. 추천 순서:

1. 🧩 문제 화면 (판 + "최선의 수는?")
2. ✅ 정답 후 화살표 + 승률 비교 막대
3. 📊 경기 리포트 (정확도 + 평가 그래프)
4. 🎯 오늘의 훈련 (대기 문제 수)
5. 🎬 복기 화면 (수 목록 + 품질 배지)
6. 📈 실력 통계 (실수 원인 분석)

요구 규격: JPEG 또는 24비트 PNG, 가로세로 비 16:9~9:16, 최소 320px, 최대 3840px
