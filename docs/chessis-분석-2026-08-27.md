## 2. 기능 전수 목록 (문자열 730개·레이아웃 59개에서 복원)

### A. 분석
1. **빠른 리포트 / 정밀 리포트** 2단 — 각각 깊이(depth) 또는 시간(초) 기준을 따로 설정
2. 백그라운드 분석 + 끝나면 알림(“🔎 Analysis Completed”)
3. **이어서 분석** — 이미 분석한 국면은 건너뛴다
4. 게임 리포트: 정확도, 평균 CPL(ACPL), 수 품질 개수
5. **수 품질 10단계** — 코드 1~10 이 그대로 잡혀 있다:
   `1 Book · 2 Genius · 3 Sharp · 4 Best · 5 ≈Best · 6 Good · 7 Inaccuracy · 8 Mistake · 9 Blunder · 10 Missed Win`
6. **Why Blunder? / Why Mistake?** — 응징 수순을 자동으로 놔 준다
7. **Retry Mistakes** — 블런더·놓친 승기·실수를 다시 맞혀 보기
8. 평가 그래프(꺾은선) ↔ 수 목록 연동, 평가 막대
9. 분석 화살표: 번호 표시 · 강도별 색(초록/노랑/빨강)
10. 리포트 숨기기/보이기, ACPL 표시 여부

### B. Key Elements (베타) — **이 앱의 독자 기능**
국면 위에 “지금 무엇이 걸려 있는가”를 겹쳐 그린다. 9가지:

| 요소 | 뜻 |
|---|---|
| 핀 걸린 기물 | 움직이면 뒤가 뚫리는 기물 |
| 무방비 기물 | 지켜 주는 아군이 없는 기물 |
| 기물 활동성 | 칸마다 “그 기물이 갈 수 있는 칸 수”를 숫자로 |
| 고립 폰 | 옆 줄에 아군 폰이 없는 폰 |
| 뒤처진 폰 | 옆 폰들보다 뒤에 있어 전진이 막힌 폰 |
| 통과한 폰 | 앞을 막는 상대 폰이 없는 폰 |
| 잡히기 쉬운 킹 | 체크를 걸 수 있는 상태인지 |
| 발견 공격 | 비켜 주면 드러나는 공격 |
| 포크 가능 칸 | 두 기물을 동시에 찌를 수 있는 칸 |

각각 **정의 + 예제 국면 + 설명**이 들어간 튜토리얼(슬라이드)까지 있다. 대국 중에도, 분석 중에도 켤 수 있다.

### C. Threats (베타)
- **전술 위협** — 지금 상대 차례라면 뒀을 최선수(=재료를 딸 수 있는 수)
- **메이트 위협** — 몇 수 안에 강제 메이트가 나는 수
- **무방비 기물 위협**
- 위협 화살표(색 지정) · 위협받는 칸 강조 · “내 차례가 아닐 때도 보기”

### D. 대국
- 난이도 6단(Beginner~Master) · ELO 지정 · **Maia(사람처럼 두는 상대)** · Chess960
- 시간 제한(분+초 증가), **엔진에게만 다른 시간**(uneven time control)
- 무르기(공정성 위해 상대에게 +10초) · 힌트/최선수 · 무승부 제안 · 기권
- **내 수 강도 실시간 표시** / 상대 수 강도 표시
- **블런더에서 자동 정지** / 실수에서 정지 → 왜 나빴는지 바로 확인
- 아무 국면에서나 시작 · 여기서부터 두기 · 지난 대국 이어하기
- 종료 사유 전부 처리(메이트·기권·시간·스테일메이트·50수·3반복·기물부족)

### E. 판·편집
- **보드 에디터** — 기물 끌어 놓기, 캐슬링 권한 O-O/O-O-O 4개, 둘 차례, 지우기/초기화
- **분석판**(자유 국면) · FEN 복사/붙여넣기/공유/검증
- 판 테마: 밝은칸·어두운칸 **색 직접 고르기**, 배경 이미지, 프리셋(brown·grass·dark wood·dark blue)
- 기물 세트 13종 + **사용자 ZIP 불러오기**(wp.svg, bp.svg … 규칙)
- 좌표·합법수 점·마지막수 강조(유형+색)·**피규린 표기**·기물 애니메이션 속도·자동재생 속도
- 끌 때 기물 확대 · **판에 화살표 자유 그리기**(색 지정) · 전체화면 · 판 뒤집기(아이디 기준 자동)

### F. 경기 보관함
- **태그**(만들기·이름바꾸기·지우기, 태그 안 경기 함께 삭제 경고)
- **필터**: 선수 이름/이벤트 검색, 결과(전체·백승·흑승·무), 색, 정렬(최신·오래된 순), 태그
- **FEN 위치 검색** — 그 국면이 나왔던 내 경기를 전부 찾는다(“Found %d games out of %d”)
- 즐겨찾기 · 최근 경기 · 여러 개 선택해 삭제 · PGN 편집 · 공유
- PGN 파일/붙여넣기(여러 판 한 번에) · **중복 감지**(“이 파일 이미 N번 넣었음”)
- **오프닝 탐색기** — 내 경기 기준 오프닝별 승률, 백/흑 따로 정렬
- **백업/복원** — 경기+설정 전부 파일 하나로

### G. 그 밖
- 엔진 설정: 스레드/코어 수, 해시(MB), **엔진 라인 수(MultiPV, Pro 는 무제한)**, 라인 자동 재생
- 유료(월/연/평생) · 프로모 코드 · 광고
- 다국어 · 알림 · 배터리 최적화 안내

## 3. 우리 앱과 맞대 보기

### 이미 우리가 가진 것 (이식 불필요)
수 품질 10단계 · Why Blunder(응징 수순) · Retry Mistakes(=🧩 문제) · 평가 그래프·막대 ·
번호 붙은 화살표 · 정확도/ACPL/추정 레이팅 · 오프닝 성적 · chess.com·리체스 가져오기 ·
엔진 대국 6단 · 판 테마 4종

### 우리가 이미 앞선 것
| | Chessis | 체스 복기왕 |
|---|---|---|
| 엔진 | SF13/14/15 (NNUE 는 30MB 별도) | **스톡피시 18 + NNUE 내장** |
| 승률 | centipawn → 시그모이드 | **엔진이 직접 내는 WDL** |
| 정확도 | 단순 계산 | 변동성 가중 + 체스닷컴 실측 대조(오차 3.3) |
| 복습 | Retry Mistakes 1회성 | **안키식 간격 반복(1→3→7→14→30→60일)** |
| 광고 | 전면 노출 | 판 화면에는 광고 없음 |
| 💎 명수 | Genius 판정만 | 희생 여부까지 재탐색으로 검증 |

### 이식할 것 (= 이번 작업 범위)
1. **Key Elements 9종** + 튜토리얼
2. **Threats 3종** + 화살표·칸 강조
3. **보드 에디터 · 분석판(자유 국면) · FEN 입출력**
4. **엔진 라인 패널(MultiPV) + 라인 자동 재생**
5. **경기 보관함**: 태그·필터·정렬·즐겨찾기·FEN 위치 검색·PGN 편집·여러 개 삭제
6. **오프닝 탐색기**(내 경기 승률)
7. **백업/복원 파일**
8. **분석 설정**: 빠른/정밀 리포트, 깊이 또는 시간, 이어서 분석, 백그라운드+알림
9. **대국 강화**: 시계, Chess960, 실수에서 정지, 내 수 강도 실시간, 기권/무승부, 이어하기
10. **판 꾸미기**: 기물 세트(ZIP 불러오기 포함), 칸 색 직접 지정, 좌표·합법수·마지막수 강조 유형,
    피규린 표기, 애니메이션 속도, 자유 화살표, 전체화면
11. **수 목록 패널**(품질 배지 + 피규린)

### 이식하지 않는 것과 그 이유
| 항목 | 이유 |
|---|---|
| SF13/14/15 · lc0 바이너리 | 우리 SF18 이 더 세다. 용량만 늘어난다 |
| Maia 가중치(50MB 내려받기) | 대신 **스톡피시 ELO 제한 + 사람다운 흔들림**으로 「사람형 상대」 구현 |
| 기물 세트 13종 원본 SVG | 리체스 계열 저작권이 세트마다 다르다. **ZIP 불러오기 기능**만 이식하고, 내장은 라이선스가 확인된 것만 |
| 유료 구독·프로모 코드 | 우리 앱은 기능 잠금이 없다 |
| Firebase·Crashlytics | 계정·서버 없음이 우리 원칙 |

# 1.4.0 — 리체스 practice·training 이식 (2026-09-06)

Chessis 이식(1.3.0)에 이어, 이번에는 **리체스**의 두 화면을 앱 안에 들였다.
그리고 폰에서 쓰다 걸린 것 네 가지를 고쳤다.

## 고친 것

| 신고 | 원인 | 고친 방법 |
|---|---|---|
| 화살표가 가늘다 | 굵기 15 고정 (viewBox 800 기준) | 보통 15 / **크게 23(기본)** / 아주 크게 32. 화살촉 배율은 반대로 낮춰(3.4→2.7→2.2) 촉만 커지지 않게. 짧은 화살표는 당기는 거리를 길이의 30%로 묶었다 |
| 밀어서 옮기고 싶다 | 누르기(click)만 있었다 | pointerdown 으로 고르고, 끄는 동안 손가락을 따라오는 유령 기물(`.drag-ghost`)을 body 에 띄운다. 판은 고르는 순간 다시 그려지므로 끄는 상태는 **모듈 바깥 + window 이벤트**로 들고 있어야 살아남는다 |
| 판 색이 변한다 | `quiz.js` 가 기본색으로 한 번 그리고, 설정이 오면 다시 그렸다 | `settingsNow()` — 앱이 뜰 때 이미 읽어 둔 설정을 기다리지 않고 바로 쓴다. 판 옵션도 `boardOpts(st)` 하나로 모아 화면마다 어긋나지 않게 했다 |
| 타격감이 없다 | 소리는 사인파 두 음, 진동은 고정 | 소리를 다시 만들었다 — 짧은 잡음(나무 부딪는 소리) + 낮은 울림. 놓기·잡기·체크·캐슬링·승격이 다 다르다. 진동도 종류마다 박자가 다르고(navigator.vibrate), 도착 칸에 파장이 퍼지며 잡는 수는 판이 2px 흔들린다 |

## 퍼즐 (리체스 training)

리체스 퍼즐 DB(수십 MB)는 폰에 넣을 수 없다. 대신 **퍼즐이 만들어지는 원리 자체**를 옮겼다.

1. **내 경기에서** — 분석 결과에 남은 실수·블런더 자리마다, 그 실수를 응징하는 수순을
   문제로 만든다. 승률이 12%p 이상 흔들린 것만 쓴다. 실제 옛 경기 11판에서 **55개**가 나왔고
   전부 끝까지 풀리는 것을 확인했다.
2. **기본 꾸러미 526개** — 스톡피시끼리 낮은 실력(0~5)으로 620판을 두게 해 자연스러운
   실수를 만들고, 깊이 16·후보 2개로 「그 수 하나만 결정적으로 이긴다」를 확인한 것만 남긴다.
   `tools/genpuzzles.mjs` · `tools/mergepuzzles.mjs`
   - **처음엔 메이트가 7개뿐이었다.** 「이미 지고 있던 국면은 퍼즐이 아니다」는 조건이
     메이트 문제를 통째로 걸러 냈기 때문이다(메이트를 당하기 직전에는 대개 이미 지고 있다).
     메이트일 때만 그 조건을 풀자 162개가 되었다.
   - **한 수 메이트는 세 수 메이트의 꼬리에서 뽑았다.** 엔진끼리 두면 한 수 메이트를
     통째로 허용하는 일이 드물어 그냥 캐서는 안 나온다. 긴 메이트의 마지막 대목은
     그 자체로 완전한 한 수 메이트 문제다 — 이렇게 86개를 얻었다.

주제 딱지(양걸이·핀·꼬치·열린 공격·백랭크·희생·승격·메이트 1/2/3…)는 `insight.js` 와
`quizgen.moveFacts` 로 국면을 실제로 읽어서 붙인다. 점수는 Elo — 퍼즐 난이도를 상대로 본다.

  틀린 것이 드러나 버렸다 — 질식 메이트는 룩이 g8 에 있어 퀸이 그냥 잡으면 끝이었고,
